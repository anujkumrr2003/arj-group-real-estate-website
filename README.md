## Installation and Setup

1. Install XAMPP.
2. Copy the project folder into `htdocs`.
3. Start Apache and MySQL.
4. Create a MySQL database.
5. Import the provided database schema, if applicable.
6. Configure the database connection using your own local credentials.
7. Open the project in your browser:

```text
http://localhost/arj-group-real-estate-website/
```

## Database

The database schema can be provided in the `database` folder.

Use your own local database credentials. No production credentials or private customer data should be included.
